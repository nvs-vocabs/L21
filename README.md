# L21 - SeaDataNet device category types
Categories used to classify devices that collect any type of physical sample in SeaDataNet.

https://vocab.nerc.ac.uk/collection/L21/current/

## Request for new terms and ways to contribute
- Requests for a new L21 can be submitted as [regular issues](https://github.com/nvs-vocabs/L21/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
